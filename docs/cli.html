Command reference

The small surface area.

Run celln --help for the authoritative reference installed with your version. These are the commands most people need.

Daily commands

CommandPurpose
celln doctorReport whether this machine can create a hardware-isolated cell.
celln setupDiscover provider CLIs, save a default, and materialise default tool images.
celln image add <image:tag>Pin and materialise an image. --tool alias=path-in-image names what to expose.
celln image spec <name>Scaffold a policy spec for a catalogue image.
celln image catalogueList catalogue tools and whether their sealed images are materialised.
celln ps -aShow recent cells and their outcome.

Let a provider write what runs

celln agent "print the first 12 fibonacci numbers"
celln agent --tool python "write fizz buzz"
celln agent agent.toml
celln agent agent.toml --prompt "review this input"

An inline prompt creates a policy in memory. A .toml argument uses the spec's declared tools, memory, hosts, and optional [agent.env]; --prompt overrides [agent].prompt. The legacy spellings --task and [agent].task are still accepted.

Run a pinned invocation

celln run reviewed.toml

celln run is the model-free path for a reviewed [run] invocation with exact, declared arguments and optional [run.env]. The declared environment is complete: Celln never inherits the host environment. A spec uses either [run] or [agent], never both.

Inspect and reproduce

celln verify          # guest attempts the hardware boundary checks
make bench-kvm        # measurements on a capable KVM host
celln ps -a --json
