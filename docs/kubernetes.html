Integration status · contract and host proof

Celln is ready to describe a run—not yet dispatch one from Kubernetes.

Sympozium keeps the AgentRun control plane. Celln now has a versioned immutable request, an explicit executable invocation, a structured terminal receipt, and truthful node eligibility. The missing component is the dispatcher that turns an admitted request into one warden, one microVM, and one sealed cell.

Current truth: Celln proves sealed guest execution on a KVM host and Kind correctly performs admission/refusal. It does not yet execute a Sympozium AgentRun in Kind. An accepted verdict is admission only, never a completed workload.

The first command builds the local node-agent image, loads it into Kind, deploys the DaemonSet, and checks the expected no_eligible_node refusal. The next two commands run real Celln agent cells on this KVM host and save raw CSV plus logs below target/kubernetes-agent-bench/.

Full stack

Diagram key: this is the target topology, not a claim that its green dispatch path is deployed in Kind. The deployed component is the node probe/admission agent; the adapter, artifact resolver, warm mote, warden dispatch, pilot completion, and receipt publisher remain unimplemented.

Celln deliberately is not a RuntimeClass: CRI gives a process a mutable filesystem and container lifecycle, while Celln needs immutable content hashes, explicit capabilities, hardware admission, and host-enforced revocation.

How one request moves

  1. Designed, not implemented in Sympozium: an AgentRun policy becomes celln.dev/v1alpha1 intent.
  2. Implemented: the node agent validates request shape and reports KVM, CPU virtualization, bootable guest kernel, stores, and capacity.
  3. Implemented: malformed or ineligible requests are refused with a stable reason; the current Kind node returns no_eligible_node.
  4. Not implemented: no dispatcher resolves artifacts, forks a mote, creates a warden, runs pilot, or publishes a receipt.
  5. Required next: only a dispatcher with that real guest evidence may return a terminal Celln receipt to Sympozium.

What Celln can hand to Sympozium today

The contract is ready for an adapter, but there is no receipt producer yet. A request can name immutable substrate, tools, predecessor data, limits, isolation requirements, and now one declared executable. A terminal receipt has immutable resolved authority and output references. Mutable AgentRun.status.result, ConfigMaps, image tags, URLs, paths, and shared volumes are not Celln authority channels.

Inside a cell

Every cell is a sealed mote. A mote is the substrate at rest; it becomes a cell only after warden forks it, seals it, and loans its declared tools.

Interpret the timing correctly. Agent-cell durations are end-to-end user latency, dominated by model generation and reproducible compilation. The microsecond warm-mote numbers are the execution-plane latency. The host has a soft 1,024-file-descriptor limit, so the 1,000-cell synthetic fork test stopped at 340 cells; the raw measurement is in target/celln-bench/m1-m2-kvm.json, not hidden.

The next Celln PR slice

Implement a local node dispatcher first: resolve one immutable mote bundle and executable from verified stores; stage manifest, tool filesystem, and fixed run.json; run pilot inside a real Celln guest; bound and content-address stdout; then emit ExecutionReceipt. It must fail closed on missing/corrupt artifacts, a manifest mismatch or revocation, a missing pilot marker, timeout, or output overflow. Only after that proof should Kubernetes transport and the Sympozium backend be wired to it.
